# الميزان — ضبط طباعة السجلات حتى 14 خانة

نسخة معدّلة من Mizan Accounting v2.7.9.7، مع ضبط اليومية العامة والأستاذ والموازين وبقية السجلات لعرض المبالغ كاملة، وتوزيع الحسابات الكثيرة على مجموعات صفحات مع تكرار الترويسات.

## تنزيل الملفات

- [تنزيل النسخة الكاملة المعدّلة — نحو 2.8 ميغابايت](https://github.com/shymaammohammad-jpg/m1/raw/refs/heads/mizan-print-14digit/downloads/Mizan_Accounting_Print_14Digit.zip)
- [تنزيل تحديث الطباعة للبرنامج المثبّت — نحو 34 كيلوبايت](https://github.com/shymaammohammad-jpg/m1/raw/refs/heads/mizan-print-14digit/downloads/Mizan_Print_Update_14Digit.zip)
- [نموذج طباعة تجريبي PDF](https://github.com/shymaammohammad-jpg/m1/raw/refs/heads/mizan-print-14digit/downloads/Journal_Print_Sample_14Digit.pdf)
- [تعليمات التحديث](downloads/README_PRINT_UPDATE_AR.md)
- [نتائج الاختبار وحدوده](downloads/VALIDATION_PRINT_AR.md)
- [بصمات SHA-256](downloads/MIZAN_SHA256SUMS.txt)

للبرنامج المثبّت، استخدم حزمة التحديث الصغيرة واتبع التعليمات المرفقة. فك الضغط أولًا، وانسخ الملفات المحددة إلى المسارات المطابقة داخل مجلد ifrs_accounting ثم حدّث المتصفح بـ Ctrl+F5. لا يحتاج إصلاح الطباعة إلى إعادة تثبيت أو استيراد قاعدة بيانات أو إعادة تفعيل.

اجتازت النسخة 108 إعدادات لفحص الطباعة، مع فحص PDF وحفظ قيم الخلايا والمجاميع. الاختبارات ببيانات اصطناعية وفي المتصفح؛ لم تُجرَ على طابعة Windows فعلية. يُفضّل A3 أفقي لليومية والأرصدة والسجلات كثيرة الأعمدة.

الملفات المنشورة هي حزم البرنامج وتحديث الطباعة، ولا تتضمن قاعدة بيانات تشغيلية للمستخدم.
