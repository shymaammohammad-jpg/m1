# رقيب — تدقيق العقود الحكومية

تطبيق عربي محلي لتنظيم التدقيق المسبق للعقود، مبني على الملفات المرجعية التي قدمها المستخدم. يضم واجهة React وخدمة FastAPI وقاعدة SQLite، ويعمل دون مفاتيح ذكاء اصطناعي أو إرسال العقود إلى خدمة خارجية.

## ما يعمل

1. إنشاء ملفات عقود مستقلة ورفع العقد والأوليات، بما فيها أرشيف ZIP.
2. اختيار سنة التعليمات حسب قاعدة المستخدم: عقد 2024 ← تعليمات 2014، ومن 2025 إلى التاريخ الحالي ← تعليمات 2025. يتيح النظام تثبيت نسخة مختلفة لحالة محددة مع سبب موثق؛ السنوات الأقدم لا تعتمد دون مراجعة والتواريخ المستقبلية مرفوضة للاعتماد.
3. مراجعة ملاءمة أعمام الديوان من حيث التاريخ والموضوع، مع الاستشهاد بصفحة الأصل.
4. مراجعة قرار مجلس الوزراء وموافقاته ومرفقاته.
5. تنفيذ 43 بند فحص مستخلصاً من المراجع، مع مستند إثبات وصفحته والمرجع والسند والملاحظات لكل نتيجة.
6. استمارة الفحص السريع الأصلية ذات الأقسام الستة و14 متطلب استيفاء و17 محور مخاطر. لا تُعبأ المخاطر أو نتائج الامتثال افتراضياً.
7. تدقيق الوثائق القياسية باستخدام مرجع يختاره المدقق وفق نوع العقد.
8. البحث المساعد في مصدر وزارة التخطيط أو قائمة رسمية مرفوعة، ثم توثيق المراجعة البشرية. عدم العثور أو تعذر الشبكة أو النص الناقص لا يثبت الخلو. الموقع نفسه يطلب مراجعة الدائرة لتأكيد الموقف القانوني.
9. معاينة تقرير عربي وطباعة PDF؛ التقرير النهائي لا يصدر قبل اكتمال الحقول والفحوص والأدلة. ظهور مخالفة موثقة لا يمنع إخراج التقرير؛ يظهر مضمون المخالفة فيه.

تعديل البيانات الجوهرية يعيد فتح نتائج التدقيق. حذف دليل يعيد فتح الفحوص المرتبطة به. تحفظ المستندات الأصلية وبصماتها SHA-256 وسجل عمليات الملف.

## التشغيل

المتطلبات المستخدمة: Linux، Python 3.12، Node 24، npm 11، Chromium، Tesseract، Poppler، وخطوط Noto العربية. نسخة بيئة العمل الحالية تتضمن الأدوات والمراجع الأصلية.

```bash
cd /workspace/m1
bash scripts/install.sh
bash scripts/start.sh
```

تعمل الخدمة افتراضياً على المنفذ 8000 محلياً، وتقدم الواجهة المبنية وواجهات API من خدمة واحدة. يمكن تغيير `AUDIT_PORT` و`AUDIT_HOST` عند الحاجة. هذا إصدار محلي لمستخدم واحد؛ يتطلب نشره متعدد المستخدمين إضافة المصادقة والصلاحيات وإعدادات الاستضافة الملائمة.

لتطوير الواجهة مع التحديث الفوري:

```bash
cd /workspace/m1/frontend
npm run dev
```

يضبط Vite تمرير `/api` إلى الخدمة الخلفية. خطوات التشغيل تفترض استخدام checkout الحالي؛ لا حاجة لإنشاء Git worktree لأن كل مهمة سحابية معزولة بالفعل.

## الملفات المرجعية والبيانات

- تحفظ بيانات العمل والمرفوعات وقاعدة SQLite في `data/`، وهي مستثناة من Git.
- المراجع الأصلية الأربعة في `data/reference_library/` مع manifest ونصوص OCR مساعدة. مستند دليل رئيس الوزراء متاح بأكمله (76 صفحة)، لكن نص OCR المحفوظ يغطي صفحات مختارة فقط ويُوسم جزئياً.
- `reference_structure.json` يوثق هيكل البرنامج والاستمارة وصفحات المصدر.
- `reference_circulars.json` يوثق الأعمام والقرارات وقائمة الأوليات والقرارات السابقة والملغاة.
- `reference_report.json` يصف التقرير البشري ذي الصفحات التسع، وأسماء أقسامه وجداوله وحدود استنساخ تنسيقه.
- أضيف النصان الرسميان من روابط الوزارة: تعليمات 2014 بنسخة تموز 2017، وتعليمات 2025 المنشورة في الوقائع العراقية 4849 بتاريخ 17/11/2025. النسخة الأولى لا تثبت شمول التعديلات اللاحقة، والثانية تتضمن التعليمات في صفحات PDF 3–56 يليها محتوى آخر في عدد الجريدة.
- تضم المكتبة أيضاً حزمة الإعمام 3429 ذات 174 صفحة بالتعليمات والضوابط العشرين، وتعديل الضابط الخامس بتاريخ 7/5/2024 وتعديل الضابط الرابع بتاريخ 30/12/2024. الإجمالي الحالي تسعة مراجع أصلية؛ لا يدعي هذا تجميع جميع التعديلات المحتملة. يعيد المثبت جلب الملفات العامة المعروفة فقط مع فحص SHA-256 ويحافظ على مراجع المستخدم.
- تراجع الأرقام والتواريخ على صورة المستند الأصلية؛ توجد ملاحظة اختلاف رقم كتاب الديوان بين ملف الأعمام واستمارة الفحص، ولم يصحح المصدر بصمت.

نسخة Git وحدها لا تتضمن بيانات `data/` أو المرفقات الأصلية؛ النسخة السحابية المعدة تحتفظ بها ضمن لقطة نظام الملفات. في تثبيت مستقل ترفع المراجع من مكتبة المراجع داخل التطبيق، أو تنقل `data/reference_library/` مع manifest. لا تنقل قاعدة بيانات ملفات العقود إلى جهة أخرى دون قصد.

يمكن عزل قاعدة البيانات بتعيين `AUDIT_DATA_DIR`. لا توضع بيانات اعتماد في الكود. تشغيل OCR للمرفوعات اختياري:

```bash
AUDIT_OCR_ON_UPLOAD=1 bash scripts/start.sh
```

OCR محدود بأول خمس صفحات من PDF لتجنب تعليق الرفع؛ توسم الوثائق الأطول جزئية وتبقى صفحات الأصل متاحة للمراجعة. قراءة النص لا تعني إجراء التدقيق القانوني. لا تنفذ النصوص أو التعليمات الموجودة داخل المرفوعات. الحد الأقصى للملف 100 ميغابايت، والأرشيف 200 عنصر و250 ميغابايت بعد الفك، مع منع المسارات غير الآمنة والروابط والضغط المفرط.

## التقرير والحدود القانونية

المخرج يحافظ على ترتيب «الإيضاحات» و«الملاحظات» وأقسام النموذج البشري، مع جداول تدخل بياناتها فعلياً وملحق الفحص السريع وفهرس الأدلة. المصدر PDF ممسوح ومكتمل لحالة سابقة؛ إعادة التنضيد ليست مطابقة بصرية حرفية، ولا ينسخ النظام توقيعاً أو ختماً أو نتائج الحالة السابقة. التقرير الناتج يحتاج اعتماد الجهة المخولة، حتى عندما تكون المراجعة البرمجية مكتملة.

اختيار سنة التعليمات مأخوذ من طلب المستخدم، وليس حكماً مستقلاً بالنفاذ القانوني. بعض الأعمام تخص آب 2026، والبرنامج يشير إلى تعليمات 2025؛ لذلك يلزم توثيق الملاءمة لكل عقد. تتضمن حزمة رئيس الوزراء نظاماً سابقاً ملغى؛ لا يطبق حد 25 مليار أو مدة 30 يوماً من النظام القديم كقاعدة حالية تلقائياً.

المادة 42 من تعليمات 2025 تربط النفاذ بمرور 90 يوماً من نشرها، والمادة 41 تتناول استمرار تعليمات 2014 للعقود المبرمة بموجبها. لذلك لا يعتمد النظام سنة العقد وحدها كسند قانوني نهائي؛ يمكن للمدقق تثبيت نسخة مختلفة وتوثيق السبب والمرجع، وتُعاد نتائج الفحص إلى المراجعة عند تغيير النسخة. يجب مراجعة التعديلات والإعمامات اللاحقة بحسب تاريخ الحالة؛ لا يدعي التطبيق تقديم موسوعة تشريعية موحدة ومحدثة تلقائياً.

كتاب الوزارة 3429 في 3/2/2026 يحدد بدء التطبيق صراحة في 15/2/2026؛ يحتفظ التطبيق بقاعدة المستخدم الافتراضية مع التنبيه لهذا القيد وإتاحة التثبيت الموثق، ولا يغيرها بصمت.

تطبق الخدمة قيود HTTPS على نطاقات الوزارة المحددة فقط، وتحترم تحويلات الشبكة وتحقق TLS. قد يتعذر الوصول لمنصة القوائم `blacklist.mop.gov.iq` في إعداد الشبكة الحالي؛ لا يُعد هذا دليلاً على الموقف القانوني. نسخ القوائم التاريخية وقرارات الإدراج أو الرفع المنفردة لا تثبت وحدها مراجعة القائمة الحالية كاملة.

## التحقق

```bash
cd /workspace/m1
.venv/bin/python -m unittest discover -s tests -v
cd frontend
npm run build
```

الاختبارات تستخدم ملفات عقود ومراجع اصطناعية في قاعدة بيانات مؤقتة، وتغطي حفظ الحالة وسنوات التعليمات وصحة الأدلة والفئات وتحديث البيانات والأرشيفات والقوائم السوداء ومنع التقرير الناقص وتصدير PDF عربي. لا تثبت هذه الاختبارات صحة تدقيق عقد حقيقي؛ لم يرفق المستخدم عقداً لفحصه في هذه الجلسة.
