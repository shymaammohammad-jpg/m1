# فحص تحديث طباعة الميزان

تم فحص 108 إعدادات طباعة على 36 نموذجًا، باستخدام Chromium وملفات CSS وJavaScript الفعلية للتطبيق: A3 أفقي وA4 أفقي وA4 عمودي، بهوامش 7 ملم. نجحت فحوص عرض الأرقام داخل الخلايا والحفاظ على محتوى الخلايا وعدم فقدان المبالغ من ملفات PDF.

تتضمن النماذج 32 نموذجًا من قوالب PHP الأصلية، وأربعة نماذج ضغط إضافية. تشمل اليومية العامة مع 0 و1 و5 و15 حسابًا، الأستاذ، ميزان الحركات، ميزان الأرصدة، اليومية المساعدة، مطابقة البنك، سندات الصرف، المخزون، الأصول، المركز المالي والدخل. تم فحص الطباعة العادية والاحترافية حيث تتوفران، والأعداد الصحيحة وثلاث منازل عشرية والفواصل والسوالب والمجاميع الأطول والأوصاف العربية الطويلة.

في المقارنة المستقلة لليومية ذات 15 حسابًا، تداخلت أرقام 180 خلية في التنسيق القديم رغم تصغير الخط إلى 4.7 نقطة. بعد التعديل لم تتداخل أية خلية مالية، وكان الخط نحو 8.5 نقطة، مع توزيع الحسابات على خمس مجموعات أعمدة.

الفحص المستقل للسجلات الطويلة تحقق من حضور المستندات المئة في اليومية وجميع حركات الأستاذ المئة، وتكرار الترويسات في كل صفحة، وظهور مجاميع اليومية مرة لكل مجموعة أعمدة ومجموع الأستاذ مرة واحدة. فُحصت الصفحات الزائدة الفارغة وأُزيل سببها في قواعد الطباعة.

نجح فحص الصياغة لجميع ملفات PHP الأصلية البالغ عددها 56، إضافة إلى ملفي JavaScript المعدلين/المضافين. اقتصرت تغييرات المصدر على أربعة ملفات للطباعة، مع تحديث بيان البصمات لأغراض التغليف. ظلت صفحات الحسابات ومنطقها وconfig.php وstorage وملفات SQL والتراخيص مطابقة للنسخة الأصلية.

هذه اختبارات طباعة ببيانات اصطناعية معزولة؛ لا تمثل تدقيقًا لصحة الحسابات أو تجربة قاعدة MySQL حقيقية أو جلسة مستخدم مرخصة. لم تُجرَ تجربة على طابعة Windows فعلية. احتفظ البرنامج بتنسيق المبالغ وحساباتها الموجودين أصلًا؛ لم يُغيّر هذا التحديث دقة التخزين أو التقريب المحاسبي.

توجد أدوات الفحص ونتائجه في /workspace/mizan-print-tests، خارج مجلد التطبيق وحزم التشغيل.
