# تحديث طباعة الميزان — 14 خانة

مخصص للنسخة المرفوعة Mizan Accounting v2.7.9.7.

يعرض المبالغ ذات 12 أو 14 خانة قبل الفاصلة، مع فواصل الآلاف والمنازل العشرية المعتمدة في البرنامج. يقيس المجاميع الأطول أيضًا، ويحافظ على نص المبلغ دون تحويله أو إعادة احتسابه.

## تحديث البرنامج الموجود على الحاسبة

1. احتفظ بنسخة احتياطية من مجلد البرنامج وقاعدة بياناتك.
2. فك ضغط حزمة Mizan_Print_Update_14Digit.zip أولًا. لا تشغّل البرنامج من داخل الملف المضغوط.
3. افتح مجلد ifrs_accounting داخل حزمة التحديث وانسخ محتوياته فوق مجلد البرنامج الحالي. المسار المعتاد هو C:\xampp\htdocs\ifrs_accounting. وافق على استبدال الملفات الواردة في الحزمة فقط، ولا تحذف مجلد البرنامج الحالي.
4. افتح البرنامج واضغط Ctrl+F5 لتحديث ملفات المتصفح.

تحتوي حزمة التحديث على أربعة ملفات للطباعة وبيان بصمات الملفات فقط. لا تتضمن config.php أو storage أو ملفات قاعدة البيانات أو التثبيت أو الترقية أو الترخيص. لا يحتاج هذا التحديث إلى تشغيل برنامج التثبيت أو install.php أو upgrade.php أو استيراد SQL أو إعادة التفعيل.

## إعداد الطباعة

- اليومية العامة وميزان الأرصدة: يفضّل A3 أفقي.
- الأستاذ وميزان الحركات وبقية السجلات: A4 أفقي عادةً؛ استخدم A3 عند كثرة المبالغ الكبيرة والأوصاف الطويلة.
- إذا كانت الطابعة A4، اختر A4 من إعدادات البرنامج. تُقسّم الحسابات الكثيرة تلقائيًا إلى مجموعات صفحات، مع بقاء المدين والدائن للحساب الواحد معًا.
- بيانات المستند ومبلغ المعاملة والمجاميع السياقية تتكرر للمطابقة بين مجموعات الأعمدة. لا تجمع القيم المكررة بوصفها معاملات جديدة.
- تطابق ورق الطابعة واتجاهه مع الاختيار داخل البرنامج، واجعل مقياس المتصفح 100%، وأوقف رؤوس وتذييلات المتصفح الإضافية. جرّب حفظ PDF قبل الطباعة الورقية.
- إذا ظهرت رسالة أن مساحة الورق لا تكفي، قلّل الهوامش أو اختر A3 أفقي. لا يختصر البرنامج الأرقام ولا يحذف فواصلها لتجاوز هذا التنبيه.

تُطبع اليومية المساعدة بأرقام مدوّرة داخل خلايا ذات ارتفاع مناسب، مع وصف عربي قابل للالتفاف. تتكرر ترويسات الجدول في الصفحات الطويلة، وتظهر المجاميع في نهاية كل مجموعة أعمدة.
