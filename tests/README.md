# اختبارات مقعد

اختبارات المحرك المستقلة:

```bash
php tests/solver.php
```

اختبارات التكامل تكتب بيانات اصطناعية، وتختبر الاستعادة والحسابات والبوابات، وتبقى بياناتها في قاعدة الاختبار. استخدم **نسخة منفصلة من مجلد التطبيق وقاعدة فارغة تنتهي بـ `_test`**، واضبط `config.php` للنسخة الاختبارية على هذه القاعدة. لا تستعمل النسخة العاملة أو قاعدة الطلبة الحقيقية.

تحتاج Python 3، وعميل MySQL وPHP في PATH أو تحديد مساراتهما. المتغيرات:

- `MAQAD_TEST_DATABASE`: مثل `maqad_test`، ويجب أن تكون فارغة قبل الاختبار الأول.
- `MAQAD_TEST_URL`: عنوان النسخة الاختبارية على localhost أو loopback، مثل `http://127.0.0.1:8095/`.
- `MAQAD_MYSQL_BIN`: مسار mysql عند عدم توفره في PATH.
- `MAQAD_PHP_BIN`: مسار PHP عند عدم توفره في PATH.
- `MAQAD_TEST_MYSQL_HOST` و`MAQAD_TEST_MYSQL_PORT` و`MAQAD_TEST_MYSQL_USER`: قيم الاتصال الاختبارية، افتراضيًا 127.0.0.1 و3306 وroot.
- `MAQAD_TEST_MYSQL_SOCKET`: مسار Unix socket للاختبار المحلي على Linux عند الحاجة.
- يمكن تزويد كلمة مرور عميل MySQL بمتغيره المدعوم `MYSQL_PWD` دون كتابتها في الاختبارات أو طباعتها. يجب أن يطابق الاتصال إعداد التطبيق الاختباري.

بعد تشغيل خادم النسخة الاختبارية:

```bash
python tests/http_integration.py
python tests/http_edges.py
```

الأول يرفض قاعدة تحوي جداول، ويختبر تهيئة نسخة جديدة. الثاني يعتمد على بيانات الأول ويغيرها. كلاهما يرفض اسم قاعدة لا ينتهي بـ `_test` وعنوانًا لا يكون loopback. تُولّد كلمات المرور والرموز أثناء التشغيل ولا تطبع. احذف القاعدة الاختبارية والمجلد المنفصل بعد الانتهاء إذا لم تعد بحاجة لهما.

لا تثبت هذه الاختبارات مطابقة التطبيق المصوّر؛ إنها تتحقق من قواعد النسخة المبنية.
